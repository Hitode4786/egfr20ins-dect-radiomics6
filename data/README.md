# Restricted clinical inputs

No clinical data are distributed with this repository.

The clinical-analysis scripts expect an authorised, de-identified analysis-ready
input bundle. The expected variables and permitted access route are described in
[`../docs/RESTRICTED_DATA_ACCESS.md`](../docs/RESTRICTED_DATA_ACCESS.md). Do not
place clinical inputs, patient-level predictions, trained clinical models, or
temporary analysis outputs under version control.

The only public result-bearing data in this repository are the fully synthetic
Figure 7 simulation outputs under `../simulation/outputs/`.
